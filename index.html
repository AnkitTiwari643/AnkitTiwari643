Real problems from production at Bazaarvoice. Real impact measured in minutes saved, dollars cut, and incidents that never happened.

PROJECT_001
Legacy Jenkins pipelines breaking team velocity
CI/CD Platform Migration to GitHub Actions
Dozens of legacy Jenkins pipelines were fragile, inconsistent across teams, and required constant maintenance — blocking engineering velocity at Bazaarvoice.
Migrated all pipelines to GitHub Actions with structured branching strategy, PR template validation, ECR artifact management, mandatory PR approvals, and a separate infra change approval gate. Deployment frequency up, overhead down.
GitHub ActionsJenkinsECRTerraform
PROJECT_002
New coupon service needed production infra from zero
End-to-End Coupon Service Infrastructure
A brand new coupon management service needed horizontally scalable, production-grade infrastructure — fully automated, with no legacy to lean on.
Designed and delivered complete infra: DNS + ALB routing → ECS containers → Aurora RDS, provisioned entirely via Terraform. Scalable, automated, and deployment-ready from day one.
ECSAurora RDSALBTerraformRoute53
PROJECT_003
14M+ emails/day during BFCM — zero margin for error
BFCM Peak Load — Zero-Incident Reliability
Black Friday & Cyber Monday: 14M+ emails/day in flight. Any infrastructure failure would have immediate, massive business impact with no recovery window.
Led full readiness: CPU/memory/healthy-node alerting across all services, capacity reservation planning, active-active multi-region with Route53 health checks for automatic failover. Zero incidents across the entire peak.
Multi-RegionRoute53DatadogPagerDutyAWS ECS
PROJECT_004
Kubernetes at 3,000+ RPS with no autoscaling or rightsizing
K8s Autoscaling & EC2 Cost Rightsizing
Production Kubernetes workloads at 3,000+ RPS had no autoscaling — every traffic spike was a risk. Oversized EC2 instances were burning unnecessary cost with no visibility.
Implemented HPA with fine-tuned resource limits for resilience. Paired with EC2 rightsizing from CPU/memory utilization analysis — substantial cost savings achieved at 0% request failure rate and zero post-migration stability issues.
KubernetesHPAEC2Cost OptimizationDatadog
PROJECT_005
Deployment-related downtime on every production release
Zero-Downtime Blue-Green Deployment Strategy
Every production release came with deployment downtime — eroding user experience and confidence in the release process across all engineering teams at Bazaarvoice.
Architected Blue-Green deployment strategy using Route53 weighted routing and ALB. Eliminated deployment downtime entirely, improved production release success rate dramatically.
Blue-GreenRoute53ALBAWS
PROJECT_006

Config Propagation Workflow Redesign
Configuration changes between upstream and downstream systems took 30 minutes to propagate globally — slowing every feature release and operational response at scale.
Redesigned the full configuration propagation workflow between upstream and downstream systems. Cut global update time by 50%: from 30 minutes down to 15 minutes, with no reliability trade-offs.
